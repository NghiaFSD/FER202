# Exercise 4: JSX and ES6

Ứng dụng hoàn thành các yêu cầu trong tài liệu:

- Giao diện JSX cơ bản, navbar, text và course list.
- `find`, `filter`, `every`, `some` với mảng people.
- `reduce` và arrow function.
- `forEach`, `filter`, `map`, `sort`, `reduce` với companies/ages.
- Object destructuring, rest parameter, array flattening, counter closure và URL query parser.
- Class `Shape`, `Rectangle`, `Triangle`.
- Promise sinh số ngẫu nhiên và báo `Error` nếu số không lớn hơn 5.

Chạy:

```bash
npm install
npm start
```
